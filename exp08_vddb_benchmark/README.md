# Эксперимент 08 — воспроизведение бенчмарка VDDB на нашей задаче

**Источник:** Tao et al., 2023, «VDDB: A comprehensive resource and machine
learning tool for antiviral drug discovery», MedComm – Future Medicine,
DOI: 10.1002/mef2.32 (`vddb_paper.pdf` в корне проекта).

В статье для предсказания противовирусной активности сравнивались 6 методов
(у них — классификация active/inactive, метрики AUC/F1/BA). Мы повторяем тот же
бенчмарк на **нашей задаче**: регрессия индекса селективности `SI VACV`,
метрика — MSE на исходной шкале (как на Kaggle).

## Методы (раздел 4.5 статьи)

| Метод | Признаки | Гиперпараметры (диапазоны статьи) |
|---|---|---|
| RF | ECFP4 (Morgan r=2, 2048 бит) | n_estimators=500, max_depth=15, max_features=sqrt |
| XGBoost | ECFP4 | lr=0.05, max_depth=5, n_estimators=100, subsample/colsample=0.9, gamma=0.05 |
| DNN | ECFP4 | MLP 2048→512→256→1, dropout=0.2, Adam, weight_decay=1e-4 |
| GCN | RDKit-граф (8 атомных признаков) | conv 128→128, dense 128 (DeepChem/Duvino-стиль) |
| GAT | RDKit-граф | 2 слоя, 8 голов, hidden=64, dropout=0.1 |
| FP-GNN | граф + ECFP4 | GAT-энкодер + fingerprint-MLP, фьюжн (idrugLab) |

Адаптации под нашу задачу:

- регрессия `log1p(SI)` вместо классификации; MSE считается после `expm1`
  на сырой шкале;
- графовые сети реализованы на чистом PyTorch (батчинг блочно-диагональной
  матрицей смежности), т.к. DeepChem/torch_geometric в среде нет;
  GAT-слой — с аддитивным вниманием (e_ij = a_l·h_i + a_r·h_j) — иначе
  плотное внимание O(N²·h·dk) не помещается по памяти/времени на CPU;
- GAT/FP-GNN: 60 эпох, batch=8 (компромисс скорость/стабильность на CPU);
  DNN/GCN: 120 эпох, batch=32;
- валидация как в exp05–07: 5-fold CV на аугментированном train (381 пример),
  метрики на официальном train (320 строк): полная MSE и **bulk** (без выброса
  SI>10 000, т.к. одна строка с SI=36 066 доминирует полную MSE);
- обучение на тех же данных, что exp06/07 (официальный train + 61 внешняя
  молекула с SI из нашей сборки ChEMBL/PubChem).

## Результаты (OOF, официальный train, MSE)

| Метод | MSE полный | MSE bulk | время (5 фолдов) |
|---|---:|---:|---:|
| **RF** | 4 230 566 | **179 635** | 4 с |
| XGBoost | 4 226 307 | 185 978 | 2 с |
| FP-GNN | 4 252 808 | 217 976 | 241 с |
| GCN | 4 288 305 | 227 414 | 54 с |
| GAT | 4 289 225 | 228 546 | 114 с |
| DNN | 4 319 737 | 297 863 | 59 с |

Для сравнения — наш бленд exp06 на тех же данных (LightGBM на FP и
ChemBERTa-эмбеддингах + двухстадийная модель + CatBoost, мультисид 3×5):
**bulk = 135 072** — лучше любого VDDB-метода.

## Выводы

1. **Ранжирование статьи в целом подтвердилось: деревья на ECFP4 — сильнейший
   бейзлайн.** В статье лучшим был XGBoost, у нас RF и XGBoost делят первое
   место (разница 3% по bulk, в пределах шума фолдов).
2. **Глубокое обучение проигрывает на наших данных.** В статье DNN/GCN/GAT
   были конкурентны на десятках тысяч молекул; у нас 381 пример и тяжёлый
   хвост целевой переменной — DL-методы на 20–65% хуже деревьев по bulk MSE.
3. **FP-GNN — лучший из DL**, т.е. идея статьи о фьюжне графа с фингерпринтом
   работает: гибрид обгоняет «чистые» GCN/GAT/DNN.
4. Для нашего финального сабмита VDDB-методы ничего не добавляют: даже бленд
   всех шести (bulk = 150 041, лучше любого одиночного VDDB-метода) уступает
   бленду exp06 (135 072). Оставляем пайплайн exp07
   (бленд exp06 + стерео-фикс + exact match) без изменений.

## Файлы

- `train.py` — воспроизводимый бенчмарк. Запуск:
  `python experiments/exp08_vddb_benchmark/train.py --methods RF,XGBoost,DNN,GCN,GAT,FP-GNN`
  (можно по частям: `--methods GAT`), затем `--aggregate` для сводной таблицы.
- `cache/` — OOF и тестовые предсказания каждого метода (`.npy`).
- `metrics.txt` — таблица результатов.
- `submission_vddb_blend_raw.csv` — сырой бленд 6 методов (597 строк).
  **Только для сравнения, не для Kaggle**: без постобработки (α, cap,
  zero-clip) и без слоя exact-match подстановок. Финальный сабмит —
  `experiments/exp07_tailfix/submission.csv`.
