# Exp 01 — бейзлайн: Morgan fingerprints + LightGBM

## Гипотеза
На малых датасетах биоактивности (~320 строк) классические ECFP-фингерпринты
с градиентным бустингом — сильный бейзлайн, сопоставимый с предобученными
трансформерами (arXiv:2508.06199 — «ChemBERTa практически эквивалентна ECFP»).

## Метод
- Признаки: Morgan FP радиус 2 (ECFP4), 2048 бит (RDKit).
- Модель: LightGBM, `num_leaves=15`, `colsample_bytree=0.4`, `reg_lambda=5`
  (регуляризация под малый датасет).
- Таргет: `log1p(SI)`; метрика MSE считается после обратного `expm1`
  на исходной шкале — как на Kaggle.
- Валидация: 5-fold KFold (shuffle, seed=42).
- Для 29 SMILES test, встречающихся в train, подставлено известное SI.

## Результат
- **OOF MSE = 4 236 759** (лучший из всех экспериментов; разброс по фолдам
  огромный из-за выброса SI=36 067 в fold 4).

## Вывод
Простой и быстрый бейзлайн оказался не хуже предобученных эмбеддингов.
Файл `submission.csv` готов к загрузке на Kaggle.
