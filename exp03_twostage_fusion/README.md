# Exp 03 — двухстадийная модель + фьюжн признаков

## Гипотеза
1) 26 % строк train имеют `SI = 0` (IC50 не измеряли — вещество неактивно).
   Для MSE выгодно предсказывать таким объектам ровно 0: отдельный
   классификатор неактивности должен снизить ошибку.
2) Фьюжн разнородных признаков (структурных FP + физхим-дескрипторов +
   предобученных эмбеддингов) богаче любого из них по отдельности.

## Метод
- Признаки: Morgan FP (2048) + ~210 дескрипторов RDKit + ChemBERTa CLS (384).
- Стадия 1: LightGBM-классификатор `P(SI == 0)`.
- Стадия 2: LightGBM-регрессор `log1p(SI)`, обучен только на активных (SI > 0).
- Порог классификатора подобран по OOF: минимум MSE на исходной шкале
  (получился 0.90 — классификатор используется очень консервативно).
- Тестировалась поправка Дуана (smearing) на смещение `expm1` — по OOF
  не помогла (4 276 895 > 4 271 717), отключена.

## Результат
- **OOF MSE = 4 271 717** — между exp01 и exp02, в пределах шума.

## Вывод
Двухстадийная схема не дала выигрыша против бейзлайна: объекты с SI=0
и так предсказываются регрессором близко к нулю (log-таргет), а ошибки
классификатора обнуляют часть истинно-активных. Но конвейер вносит
разнообразие в ансамбль exp04.
