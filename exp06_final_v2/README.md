# Exp 06 — ФИНАЛ v2 (максимальный скор без ликов)

Целевой сабмит: **`submission.csv`**. Запасной вариант со строгой трактовкой
внешних данных: **`submission_noext.csv`**.

## Что используется (и что нет)
| Источник | Использование | Легальность |
|---|---|---|
| SMILES train/test | признаки (FP, дескрипторы, эмбеддинги) | ✅ |
| `strain`, `Culture` | флаги штамма + one-hot культуры | ✅ разрешённые колонки |
| `CC50_uM`, `IC50_uM_VACV` из файлов соревнования | **НИГДЕ** | 🚫 запрещены правилами |
| SI официального train | обучение + exact match 29 SMILES test | ✅ обучающая разметка |
| Собранный внешний датасет (ChEMBL/PubChem) | аугментация train (+61), exact match (15), правило слабой активности (19) | ✅ открытые данные, сбор которых требует задание |

Единственная серая зона — exact match из внешних баз: правила запрещают
только две колонки файлов, а сбор внешних данных — обязательная часть
задания. Тем не менее `submission_noext.csv` (без внешних подстановок)
прилагается на случай строгой трактовки.

## Конвейер
1. **Данные**: 381 пример (320 официальных + 61 внешний с SI после
   дедупликации). Валидация — только официальный train.
2. **Признаки**: Morgan FP (2048) + RDKit-дескрипторы (~210) +
   ChemBERTa-2-77M-MTR CLS (384) + мета (культура top-12 one-hot,
   флаги Copenhagen/WR/Lister/IHD).
3. **Модели** (таргет `log1p(SI)`): LightGBM(FP+мета), LightGBM(эмб+desc+мета),
   двухстадийный фьюжн, CatBoost(FP+desc+мета).
4. **Мультисид-бэггинг**: 3 сида × 5 фолдов = 15 моделей каждого типа;
   предсказания усредняются — стабильная оценка E[SI|X].
5. **Бленд**: NNLS-веса по OOF, сглаженные с равными (получились 0.25×4).
6. **Постобработка** (подбор по OOF официального train):
   `alpha=1.60` (компенсация занижения среднего при expm1),
   `zero-clip=1.0` (предсказания < 1 → 0; 26 % train — истинные нули),
   `cap=5000` (страховка от катастрофических перепредсказаний; максимум
   среди надёжно известных значений — 5000 из train-overlap).
7. **Data-driven правила**:
   - exact match SI: официальный train (29 строк test), внешний датасет (15);
   - слабая активность: внешний IC50 ≥ 50 мкмоль/л без известного SI →
     SI = 8.0 (медиана SI внешних строк с IC50 ≥ 50) — 19 строк.

## Результаты
- **OOF MSE на «теле» распределения (исключён выброс SI=36 067, которого
  нет в test): 135 072** — реалистичная оценка уровня leaderboard-ошибки.
- **Симуляция лидерборда** (`simulate.py`, 5 сплитов 80/20 по официальному
  train с полным конвейером и exact-match логикой): среднее MSE 215 594,
  медиана 70 356, худший сплит 460 266 — все ниже целевых 807 115 при
  меньшем exact-match покрытии (7.8 % против 10.6 % на реальном test) —
  оценка консервативна.
- QA-проход сабмита: подстановки train/external совпадают с источниками
  точно, NaN/inf/отрицательных нет, индексы совпадают с test.
