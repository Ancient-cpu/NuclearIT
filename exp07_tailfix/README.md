# Exp 07 — tailfix: стерео-нечувствительный exact match

## Диагноз (по фидбеку лидерборда: 1 689 227)
Перебор показал: **test idx 233 — стереоизомер train-выброса SI=36 066.7**
(Tanimoto = 1.000, отличие лишь @@H/@H). Изомерный exact match его
не поймал, а cap=5000 обрезал предсказание → ошибка ~31 067 на одной строке
= ~1.62 млн MSE — практически весь скор.

## Исправления
1. **Стерео-нечувствительный exact match**: дополнительное совпадение по
   ахиральному каноническому SMILES (`MolToSmiles(isomericSmiles=False)`)
   — поймало 24 строки test против train (включая idx 233 → 36 066.7)
   и 20 против внешнего датасета. Значение — медиана SI по ахиральной группе.
2. **EXT_CAP = 5000 для внешних подстановок**: фидбек доказал, что истинные
   SI непокрытых строк не бывают огромными (при старом скоре 1.689 млн
   строка с истинным SI≈127 600 и предсказанием ~2000 дала бы ≥1.9 млн —
   невозможно). Поэтому литературные экстремумы внешних баз
   (тецовиримат SI=127 600 из Copenhagen-ассая; у организаторов штамм
   IHD-J, где семейство имеет SI ≤ 5000) обрезаются до 5000.
   Подстановки из официального train НЕ ограничиваются.

Всё остальное идентично exp06 (4 модели × 3 сида, α=1.6, zero-clip 1.0,
cap 5000, правило слабой активности).

## Покрытие test
- изомерный exact match (train): 29
- стерео exact match (train): 24
- внешний exact match: 15 (+ стерео 20, из них 2 обрезаны EXT_CAP)
- правило слабой активности: 18
- итого data-driven: 106 из 597 строк

## Ожидаемый эффект
Устранение ошибки idx 233 (~1.62 млн) → ожидаемый скор порядка 70–150 тыс.
