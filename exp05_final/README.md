# Exp 05 — ФИНАЛЬНОЕ решение (рекомендуемый сабмит)

## Что это
Итоговая модель, объединяющая всё, что показало пользу в exp01–exp04,
плюс улучшения, направленные именно на метрику соревнования (MSE по сырому SI).

## Соответствие правилам (без ликов)
- Колонки `CC50_uM` и `IC50_uM_VACV` **не используются нигде** — ни в признаках,
  ни в предсказаниях.
- Внешние данные (`data_collection/collected_vacv_dataset.csv`) участвуют
  **только как дополнительные обучающие примеры** — это прямо предусмотрено
  заданием. Подстановки значений из внешних баз в test **нет**.
- Подстановка известных SI делается **только** для SMILES test, совпадающих
  с официальным train (29 шт.) — это использование обучающей разметки.
- Все гиперпараметры (веса бленда, порог, alpha) подобраны по out-of-fold
  предсказаниям официального train — никакой информации из test.

## Состав решения
1. **Аугментация train**: +59 молекул с SI из собранного внешнего датасета
   (после дедупликации с train) → 379 обучающих примеров.
2. **Признаки**: Morgan FP (2048), ~210 дескрипторов RDKit, эмбеддинги
   ChemBERTa-2-77M-MTR (CLS, 384), one-hot клеточной культуры `Culture` (top-12).
3. **Четыре модели**: LightGBM(FP+culture), LightGBM(эмбеддинги+дескрипторы
   +culture), двухстадийный фьюжн (классификатор SI=0 + регрессор),
   CatBoost(FP+дескрипторы+culture). Обучение на `log1p(SI)`.
4. **Блендинг**: веса — NNLS по OOF, сглаженные с равными (0.5·NNLS + 0.5·uniform)
   против переобучения на 320 строках.
5. **Масштабирование α**: оптимальный множитель `Σ(y·p)/Σ(p²)` по OOF
   (компенсация занижения E[SI] при expm1-обратном преобразовании),
   ограничен диапазоном [0.8; 2.0], применяется при улучшении OOF.
6. **Валидация строго по официальному train**: внешние строки обучают,
   но не валидируют — их распределение (SI до 127 600) не соответствует
   leaderboard и ломает и метрику, и подбор α.

## Результат (5-fold OOF, только официальный train)
| Модель | OOF MSE |
|---|---|
| lgbm_fp | 4 180 526 |
| lgbm_emb | 4 172 427 |
| twostage | 4 570 044 |
| catboost | 4 223 986 |
| **BLEND + α=1.11** | **4 173 551** |

Лучший результат всей серии (exp01: 4 236 759). Разница с одиночными
моделями в пределах шума (метрика доминируется выбросом SI=36 067),
но финальный конвейер устойчивее за счёт ансамбля и аугментации.
