# Exp 04 — ансамбль (блендинг) exp01 + exp02 + exp03

## Гипотеза
Усреднение предсказаний трёх разнородных конвейеров (структурные FP,
предобученные трансформерные эмбеддинги, двухстадийный фьюжн) снижает
дисперсию ошибки и устойчивее к сдвигу распределения между train и test,
чем любая одиночная модель.

## Метод
- Те же 5 фолдов (seed=42): каждая модель обучается на своих признаках,
  предсказания усредняются на исходной шкале SI.
- Двухстадийная часть использует свой порог (0.90), подобранный по её OOF.
- Overlap train/test (29 SMILES) — подстановка известных SI.

## Результат
- exp01: 4 236 759 | exp02: 4 286 586 | exp03: 4 271 717
- **BLEND OOF MSE = 4 263 278**

## Вывод
По OOF бленд уступает только exp01 (разница < 1 %, в пределах шума —
метрика доминируется одним выбросом), но как компромисс между
бейзлайном и разнообразием представлений это **рекомендуемый сабмит**
для Kaggle. Альтернатива — чистый exp01.

## Запуск
```bash
python experiments/exp04_ensemble/train.py
```
