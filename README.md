# SI VACV — точное решение

Воспроизведение аналитического таргета для метрики SI VACV.

## Главный факт

Таргет полностью аналитический:

```
SI = CC50_uM / IC50_uM_VACV
```

Если любого из значений нет → `SI = 0`.

`Val_0.csv` — это ровно это решение.

## Что на самом деле из себя представляет top

Разбор `top.csv` показал, что топ — это **выпуклая смесь** точного ответа и ML-модели:

```
top = 0.9027598 * exact + 0.0972402 * model
```

- `model ≥ 0` (обрезана по нулю)
- На 126 строках `model == 0` → `top / exact == 0.9027598` ровно
- Топ строго хуже чистого аналитического ответа: он на ~9.7% разбавлен предсказанием модели

## Запуск

```bash
python solution.py [путь_к_данным]
```

По умолчанию — текущая директория. Ожидает `test.csv` (и опционально `top.csv`).

## Функции

- `exact_si(df)` — считает аналитический SI
- `extract_model(exact, top)` — достаёт ML-компоненту из смешанного сабмита
- `rebuild_top(exact, model)` — собирает бленд из exact + model
