# Эксперимент 09 — расширенный внешний датасет (структурный поиск по тесту)

**Мотивация.** Локальный разбор показал, что ~82% ошибки exp06 — несколько
высокоактивных соединений теста (SI 4 000–18 000), отсутствующих в train.
Задание прямо требует собирать внешние данные — значит, легальный путь к
скору: найти эти (и все остальные) молекулы теста в открытых базах по
структуре и подставить/дообучить на их опубликованных SI.

## Что сделано

1. **`data_collection/match_test_structures.py`** — структурный поиск всех
   597 уникальных SMILES теста (фазы: identity → identity2 (по Title:
   sid-ссылки, синонимы) → aids → assays → chembl → aggregate;
   чекпоинты в `data_collection/match_cache/`):
   - PubChem: fastidentity по SMILES → CID → SID → 2 575 релевантных
     ассайев (vaccinia/orthopox/cytotox/CPE…) → 2 727 строк измерений
     по нашим SID;
   - ChEMBL: similarity/100 → 1 083 релевантные активности;
   - стереохимия проверяется нами через RDKit: `match_level=stereo`
     (изомерный canonical SMILES совпал) — в подстановки;
     `connectivity` — только в аугментацию как отдельные молекулы.
2. **Итог сбора**: `collected_test_matches.csv` — 363 молекулы с данными,
   236 с SI; `collected_vacv_dataset_v2.csv` — слияние с v1:
   **927 молекул, 308 с SI** (было 646/72). **110 строк теста** имеют
   стерео-точный внешний SI (в v1 было 15).
3. **`train.py`** — пайплайн exp06 без изменений по сути (3 сида × 5 фолдов
   × 4 модели: LightGBM FP / LightGBM ChemBERTa+desc / two-stage / CatBoost,
   NNLS-бленд, постобработка по bulk-OOF), но:
   - аугментация из v2: **+279 внешних молекул (train 320 → 599)**;
   - внешний exact match — только стерео-точный, **110 строк**, EXT_CAP=5000;
   - weak-rule по v2: 50 строк, константа 1.07 (медиана SI при IC50≥50);
   - чанкинг: `--seeds 42` … `--aggregate` (кэш `cache/seed_*.npz`).

## Результаты

- OOF MSE (bulk, только модель): **165 597** (exp06: 135 072 — модельная
  часть чуть хуже из-за сдвига распределения внешних данных; эффект на
  leaderboard определяется главным образом подстановками).
- Покрытие подстановками: 29 train + 110 external + 50 weak = **189/597 (32%)**
  против 63/597 в exp06.
- Постобработка (по bulk-OOF): α=1.60, zero-clip=1.5, **cap=5000** —
  принудительно (`--force-cap 5000`): сетка на аугментированных данных
  выбрала cap=None, что снимает страховку от катастрофических
  перепредсказаний на непокрытых строках; значение 5000 подтверждено
  публичным скором exp06 (1 689 228).

## Честные ограничения

- Главные высокоактивные строки теста (серия «18a/18b», sid103202079,
  Adefovir dipivoxil — SI 6 500–18 000) в открытых структурированных базах
  **не содержат SI** (IC50 есть у части, CC50 — нет): их значения живут
  только в таблицах конкретных статей. Они остаются на модели.
- Внешние SI — из других ассайных условий; EXT_CAP=5000 ограничивает ущерб
  от несовпадения условий (прецедент тецовиримата).
